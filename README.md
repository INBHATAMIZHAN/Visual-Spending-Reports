# Visual Spending Reports

A Windows desktop banking dashboard built with WPF and .NET 8. The app presents
visual reports for spending and transactions.

## Requirements

- Windows
- .NET 8 SDK

## Run

From the repository root:

```powershell
dotnet run --project .\BankingDashboard\BankingDashboard.csproj
```

## Project layout

- `BankingDashboard/` - WPF application source and project file
